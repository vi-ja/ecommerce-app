# AstraCart

A polished e-commerce catalog experience built with HTML5, CSS3, and vanilla JavaScript. It includes:

- Modular frontend structure
- Client-side routing with history API
- Product catalog with search and filter controls
- Product detail and cart views
- Local storage persistence for cart state
- Responsive layout for mobile, tablet, and desktop

## Run locally

Open index.html in a browser, or serve the folder with a static server such as:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
